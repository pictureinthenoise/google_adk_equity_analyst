# Evaluation

When asked to evaluate bear case and bull case analyses and form an investment thesis, you will use the following rubric to create a score for each analysis:

## Rubric

* **CLEAR LANGUAGE** [Score from 0 to 5 points]: Analysis uses direct, no-jargon language and minimizes the need for exaggeration to communicate key points. In relation to the latter, a good analysis uses "fragile competitive position" instead of the exaggerated form "highly fragile competitive position".
* **FACT BASED** [Score from 0 to 10 points]: The main points of the analysis are grounded in quantitative facts. For example, a bull-case argument that revenue is likely to increase because the company's key market will grow at an 8% CAGR is considered to be stronger than a similar, but weaker, argument that suggests revenue will increase because the company's key market is strong and growing.
* **GENUINE INSIGHTS** [Score from 0 to 10 points]: The main points of the analysis do not merely regurgitate information from primary sources, but rather reflect genuine insights drawn from unique interpretations of available information and data.

The lowest possible score for an analysis is 0 and the highest possible score is 25.

## Recommendation

The investment thesis should present a final recommendation of either: **STRONG SELL**, **SELL**, 
**HOLD**, **BUY**, **STRONG BUY**. Use the following criteria to assign a recommendation:

* Bear-case analysis scores higher and rubric score >= 18: **STRONG SELL**.
* Bear-case analysis scores higher and rubric score < 18: **SELL**.
* Bear-case and bull-case analyses have the same rubric score: **HOLD**.
* Bull-case analysis scores higher and rubric score < 18: **BUY**.
* Bull-case analysis scores higher and rubric score >= 18: **STRONG BUY**.
